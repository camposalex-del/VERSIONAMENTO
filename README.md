# Meu Projeto

## Descrição
Projeto desenvolvido para praticar versionamento com Git e GitHub, incluindo branches, merges, rebase, tags, Issues e Pull Requests.

## Instalação
1. Instale o Git.
2. Clone o repositório:
   git clone https://github.com/camposalex-del/VERSIONAMENTO.git
3. Entre na pasta:
   cd VERSIONAMENTO

## Como usar
Consulte os arquivos deste repositório para acompanhar os exercícios e exemplos de versionamento.
Para visualizar o histórico de commits, execute:
   git log --oneline --graph --all
